느낀 점 : 프론트엔드를 담당하며 사용자 중심의 UI/UX를 조사하고 SPA에 맞는 화면 설계를 고민하는 과정이 얼마나 중요한지 깨달았습니다. 또한 라우팅 구조를 설계하면서 React Native의 강점인 컴포넌트 재사용성을 어떻게 구조적으로 나눠야 할지 고민하고 정립할 수 있었고, 이 경험은 이후 프로젝트를 진행하는 데 큰 도움이 되었습니다.

iEUM-Market

 Github 
Personal Project
기술 스택 : React, Zustand, Node.js, Express, JWT, Chart.js

프로젝트 동기/목표 : 지역 특산물과 로컬 상품의 온라인 판로를 확대하여 지역 생산자의 판매 기회를 높이고, 지역 경제 순환을 촉진함으로써 지방 소멸 문제 완화에 기여하는 것을 목표로 개발했습니다.

작업 과정 : 지역 경제 순환을 목표로 한 이음마켓 프로젝트에서 먼저 Router.js를 통해 홈, 상품 상세, 카테고리, 검색, 마이페이지, 게시판 등 전체 페이지 라우팅 구조를 설계했습니다. 이후 Express 서버에 auth, products, cart, order, board 라우터를 기능별로 분리하여 구성하고, JWT 기반 인증을 이용해 회원가입과 로그인 로직을 구현했습니다. 장바구니는 Zustand를 활용하여 클라이언트 상태를 관리하고 서버와 동기화되도록 설계함으로써 항상 최신 상태가 반영되도록 했습니다. 다른 쇼핑몰과의 차별점으로 Chart.js를 이용해 지역별 판매 현황을 시각화하여 사용자가 판매량을 한눈에 파악하고, 자연스럽게 판매량이 낮은 지역에도 관심을 가질 수 있는 흐름을 구성했습니다. 마지막으로 지역 상품 판매자와 소비자 간 소통을 위한 게시판 기능을 추가하여 전체 서비스 흐름을 완성했습니다.

느낀 점 : 이 프로젝트를 진행하며 다른 쇼핑몰 프로젝트와의 차별점을 만들고 싶다는 생각이 강했습니다. 이를 위해 경쟁 사이트를 분석하며 서비스의 목적성을 명확히 세울 수 있었고, 상품 판매량 데이터를 JSON 형태로 재가공하는 과정을 통해 데이터가 프로젝트의 핵심 목표와 자연스럽게 연결될 수 있다는 점을 깨달았습니다.

Reservation Project

 Github 
Personal Project
기술 스택 : JavaScript ES Modules, Playwright, Electron, Node.js

프로젝트 동기/목표 : 네이버 예약 서비스를 이용할 때 원하는 날짜와 시간을 직접 확인하고 반복적으로 예약 과정을 진행해야 하는 불편함이 있었습니다. 이러한 반복 작업을 자동화하면 사용자의 시간과 입력 부담을 줄일 수 있다고 생각해 웹 예약 자동화 프로그램을 개발하게 되었습니다.

작업 과정 : 네이버 예약 페이지의 구조와 실제 예약 흐름을 먼저 분석한 뒤, Playwright를 활용해 날짜와 시간 선택, 예약 버튼 클릭 등의 과정을 자동화했습니다. DOM 요소 생성 시점에 따라 자동화 동작이 불안정해지는 문제가 발생해 페이지 처리 속도를 직접 확인하고, 클릭 이후 필요한 로딩 시간을 하드코딩하여 안정적으로 다음 동작이 실행되도록 처리했습니다. 이후 Electron을 활용해 사용자가 별도의 개발 환경 없이 사용할 수 있도록 인터페이스를 구성하고 Windows 실행 파일(.exe) 형태로 패키징했습니다.

느낀 점 : 웹 자동화를 구현하며 단순한 기능 개발뿐 아니라 페이지 처리 속도와 실행 환경까지 고려해야 안정적인 프로그램을 만들 수 있다는 점을 배웠습니다. 또한 Electron을 통해 실제 사용자가 실행할 수 있는 형태로 배포하면서 개발부터 배포까지의 전체 과정을 경험할 수 있었습니다.

TennisFolio

 Github 
Team Project
기술 스택 : React, Node.js, MySQL, KakaoPay API

프로젝트 동기/목표 : React 프론트엔드 구조에 맞춰 Node.js와의 비동기 연동을 익히고, 정적 데이터를 CRUD 방식으로 다루며 MySQL 쿼리 작성 능력을 실전에서 연습하고자 본 프로젝트를 진행했습니다. 특히 4인 팀 프로젝트로 진행하여 협업 경험을 쌓는 것에도 중점을 두었습니다.

담당 역할 : 4인 팀 프로젝트에서 best_product 테이블을 활용한 Hot Products 조회 API를 구현하고, 장바구니 상품 추가, 수량 변경, 삭제, 조회 기능을 CRUD 형태로 개발했습니다. 또한 카카오페이 결제 API 연동을 담당하여 결제 준비부터 승인, 성공 페이지 이동까지 전체 결제 프로세스를 구현했습니다.

느낀 점 : 프로젝트 초반에는 팀원 간 Git 사용 방식이 맞지 않아 브랜치 충돌이 잦았고, 이로 인한 협업 갈등도 있었습니다. 이를 해결하기 위해 팀원들과 push/pull 시점을 사전에 정해 작업 시간을 조율했고, 이후 충돌 빈도를 크게 줄일 수 있었습니다. 개발 과정에서는 Hot Products 데이터가 화면에 정상적으로 표시되지 않는 오류가 발생했는데, 콘솔 에러와 서버 로그를 순차적으로 추적한 결과 MySQL 외래키 쿼리문에 문제가 있음을 확인했습니다. 이를 해결하기 위해 best_product 테이블과 category_id를 병합하는 방식으로 쿼리 구조를 재설계하여 문제를 해결했습니다.

현재는 Node.js, Python, MySQL을 활용한 풀스택 개발 부트캠프에 참여하며 꾸준히 역량을 키워가고있습니다.
